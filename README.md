**Independent Engineering Project** · Docker · Kubernetes · DevSecOps

A hands-on implementation of security controls across a containerized application stack, focusing on workload isolation, secrets management, policy enforcement, and visibility.

**What this demonstrates**
- Container and Kubernetes workload hardening.
- Kubernetes NetworkPolicies and workload isolation.
- Image and Kubernetes vulnerability scanning with Trivy.
- Secret scanning with Gitleaks and IaC security checks with Checkov.

- Monitoring and alerting using Prometheus, Grafana, and Wazuh.
- Security evidence collection and documentation.

**Engineering focus:** Implementing and validating security controls across the application lifecycle rather than relying on vulnerability scanning alone.
